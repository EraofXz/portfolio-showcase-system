# Portfolio Showcase System

Full Stack Web Development - Mini Project 2 (Politeknik Malaysia - DFP40443)

## Quick Setup Instructions

1. **Clone or pull the repository:**
   ```bash
   git pull origin main
   ```
2. **Start Laragon (Apache & MySQL)**.
3. **Initialize Database & Seed Default Accounts:**
   Open your browser and visit:
   ```text
   http://localhost/portfolio-showcase-system/seed.php
   ```
   *(This automatically creates the default categories and the administrator account if not present).*

---
